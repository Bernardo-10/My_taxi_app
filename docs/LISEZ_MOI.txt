⚠️ IMPORTANT - VÉRIFICATION EN BD

Après qu'un chauffeur accepte une course, vérifiez dans phpMyAdmin:
taxi_app > rides

Les colonnes DOIVENT être remplies:
✅ driver_lat = coordonnée GPS (ex: 4.0511)
✅ driver_lng = coordonnée GPS (ex: 9.7679)
✅ driver_name = 'Test Driver'
✅ driver_plate = 'LT 000 BD'
✅ status = 'accepted'

Si driver_lat/lng sont NULL → Le GPS du chauffeur a échoué

💡 FLUX COMPLET CORRIGÉ

1. Chauffeur clique "Accepter"
   → acceptRide() récupère GPS
   → Envoie lat/lng à accept_ride.php
   → Position enregistrée en BD ✅

2. Chauffeur se déplace
   → updateDriverPosition() récupère GPS toutes les 10s
   → Envoie lat/lng à update_ride_driver_position.php
   → Position mise à jour en BD ✅

3. Client voit le taxi
   → Récupère position chauffeur de get_driver_location.php
   → Affiche marqueur 🚕 à la bonne position ✅
   → Trace itinéraire chauffeur → client ✅
